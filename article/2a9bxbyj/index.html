Ubuntu24安装Mysql

约 406 字大约 1 分钟

2025-03-12

环境信息

Ubuntu 22-24 应该都是可以的
安装的mysql为8.0版本

2025/8/30更简单的安装方式

【最新】非常详细 ubuntu24安装mysql 8.0保姆级教程_ubuntu安装mysql8.0-CSDN博客

ubuntu防火墙ufw使用方式

ufw 完整使用教程 - 玩客

安装mysql

sudo apt-get update # 更新安装包工具
sudo apt-get install mysql-server # 安装mysql 确认按y

启动mysql

sudo service mysql start # 启动mysql
# sudo service mysql stop 停止mysql
sudo service mysql status # 查看mysql状态

mysql开机自启

sudo systemctl enable mysql

配置mysql登录权限

mysql登录

mysql -u root -p # 第一登录没有密码，直接回车

设置root用户连接密码

use mysql; # 进入mysql

select host, user, authentication_string from user; # 查看需要修改的root用户数据

ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '设置新的密码'; # 为root账号赋权

FLUSH PRIVILEGES; # 刷新权限

exit;  # 推出mysql控制台

设置远程访问登录

设置账号权限

#进入mysql
use mysql;
 
#设置登录ip为%通配符，取消登录ip限制
update user set host = '%' where user = 'root' and host = 'localhost';
 
#刷新权限
FLUSH PRIVILEGES;
 
#查看数据情况
select host, user, authentication_string from user;
 
#退出mysql控制台
exit;

修改配置文件

#修改mysql配置文件，取消对远程ip为127.0.0.1的绑定
#将bind-address、mysqlx-bind-address这两行注释掉
vim /etc/mysql/mysql.conf.d/mysqld.cnf

重启mysql

service mysql restart

防火墙放行

如果是云服务器，还需要在安全组中开放3306端口

#服务器防火墙开放3306端口
sudo ufw allow 3306/tcp
