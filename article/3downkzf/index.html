object-fit:

  1. fill(默认属性, 默认缩放到指定大小,宽高比例不合适,会强制拉伸修改宽高比例)
  2. contain(默认缩放到指定大小,宽高比例不合适,会有留白)
  3. cover(默认缩放到指定大小,宽高比例不合适,通过裁剪的方式来维持宽高比例)
  4. none(不缩放,使用图片默认大小)
  5. scale-down

flex布局常用

.layout {
    display: flex; /*使用flex布局*/
    flex-direction:  row | row-reverse | column | column-reverse; /*主轴排列方式*/
    justify-content: /*主轴上的对齐方式*/
    align-items: /*交叉轴的对齐方式*/
}

.item {
    flex: 0 1 auto; /*默认取值, 第一个值表示是否能增长,第二个值表示是否能缩小,第三个值表示初始带下,即先按内容值计算,有剩余也不会增加,空间不够会缩小来适配*/
    flex: 1; /*占用剩余所有空间,等同于 1 1 0 */
    flex: none; /*该是多少就占多少,不会增加也不会减小等同于 0 0 auto */
}

命名规范

  1. 项目名 kebab-case（短横线命名法），全部小写 示例 uni-app

  2. 目录名 同项目名 使用kebab-case（短横线命名法），全部小写 如果是模块名 使用动+宾

  3. 页面名 大驼峰命名法，且以Page结束 如HomePage.vue

  4. 组件名（SFC） 大驼峰命名法

    // 官方针对基础组件名的规范
components/
├ BaseButton.vue
├ BaseTable.vue
├ BaseIcon.vue

// 官方针对单例组件名的规范
components/
├ TheHeading.vue
├ TheSidebar.vue

// 官方针对紧密耦合组件名的规范
components/
├ TodoList.vue
├ TodoListItem.vue
├ TodoListItemButton.vue

// 我们建议的组件命名规范
components/
├ base(或者shared)/   (基础组件使用文件夹管理)
├─ Button.vue
├─ Table.vue
├─ Icon.vue
├ layout/           （单例组件或功能性交互组件，文件夹名称需表意，不再使用「The」作为前缀）
├─ AppHeading.vue
├─ AppSider.vue
├ todo-list/        （遵循目录命名规范，使用kebab-case进行文件夹命名）
├─ index.js         （有必要时提供入口文件统一引入，若无必要则省略）
├─ TodoList.vue     （组件命名保留父组件名字）
├─ TodoListItem.vue
├─ TodoListItemButtom.vue

  5. 样式类名 BEM命名法 使用类名前缀与组件名称相关联，以避免命名冲突，如 user-profile__avatar。对于状态类，使用描述性命名，如 is-active、is-disabled。

  6. 变量命名 小驼峰命名. 必须有意义

    页面列表：List为后缀，如goodsList 
页面详情：Details为后缀，如goodsDetails 
页面状态值: 必须是bool类型, is作为前缀. 如: isShow

  7. 方法函数命名 小驼峰命名，必须有意义

    跳转页面: to+目录名/页面名 toGoodsDetail(), toMy()
获取方法: get+变量名 getGoodsList()
更新方法: up+变量名 upIsShow()
提交方法: submit前缀 submitOrderData	(防快速点击: 提交数据需要做防止快速重复点击, 以3秒为例. 防止重复向服务器发送数据)

  8. js文件名 小驼峰命名法 或者 kebab-case（短横线命名法）

  9. 其他文件（如CSS、LESS等）：除.vue文件外，其他文件统一使用kebab-case（短横线命名法）示例 my-component.less

网页适配

个人总结的终极方案：rem+响应式布局+媒体查询

  1. 确定设计稿的宽度,字体大小
  2. 根据设计稿宽度,客户端宽度动态计算根节点字体大小，单位使用rem（这部分可以使用vw,vh替换也可以）
  3. 可以使用响应式布局（最大的痛点就是浏览器缩放到一定程度，会造成布局混乱），但是必须确定宽度范围，超出宽度的范围使用媒体查询固定页面大小，此时浏览器缩放会转化放大镜缩放效果
  4. 所有的图片，视频之类的行块级元素，建议定宽，在高度上进行拉伸

api封装

const BASE_URL = "YOU_BACKEND_URL";

const request = (params) => {
	
	let url = params.url; 
	// 如果未传值，默认为GET方法
	let method = params.method || "GET"; 
	
	let data = params.data || {}; //默认为空
	
	let header = {
		'Content-Type': 'application/json'
	};
	
	// 如果有token的话动态获取
	// if (uni.getStorageSync("token")) header['satoken'] = uni.getStorageSync("token");

	return new Promise(resolve => {
		// 切换加载框
		uni.showLoading({
			title: '加载中'
		});
		// 发起请求
		uni.request({
			url: BASE_URL + url,
			method: method,
			header: header,
			data: data,
			// 最大响应时间 单位ms
			timeout: 5000,
			success: resp => {
				let code = resp.data.code;
				let message = resp.data.message;
				// 根据状态码进行对应的回显
				switch (code) {
					case 0:
						// 成功回显
						uni.showToast({
							title: message,
							duration: 500
						});
						resolve(resp.data);
						break;
					case 1:
						uni.showModal({
							title: '客户端错误',
							content: message,
							showCancel: false
						});
						break;
					case 2:
						uni.showModal({
							title: "服务端错误",
							content: message,
							showCancel: false
						});
						break;
					default:
						uni.showModal({
							title: "错误",
							content: "遇到未知错误，请联系管理员",
							showCancel: false
						});
				}
			},
			fail: err => {
				uni.showModal({
					title: '连接错误',
					content: '连接超时,请稍后刷新重试,若多次重试无果，请联系管理员',
					showCancel: false, // 不显示取消按钮
				});
			},
			complete() {
				uni.hideLoading();
			}
		});
	});
}

export default {
	BASE_URL,
	//获取手机验证码
	getVerificationCode(phoneNumber) {
		return request({
			url: '/api/public/phoneCode?phoneNumber=' + phoneNumber,
			method: 'POST',
		});
	}
}
