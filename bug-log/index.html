前端打包后页面为空

场景：前端打完包后，发给运维，运维部署nginx后，发现报错，页面空白

原因：在vue.config.js文件里的module.exports中有个属性叫做publicPath，这个属性值会变成index.html引入其他文件的src值，默认是/，如果运维在配置nginx容器的时候，路径不是根路径的话，就会报错，找不到要引入的文件，所以此值要写成./,使用相对路径。

参考：vue打包之后出现空白页的原因以及解决方式_vue打包后打开页面是空白的-CSDN博客

VITE环境变量不生效

场景: 前端打包后部署在服务器上,报错

原因: 在.env.develop 和.env.product文件中配置的环境变量没有生效, 是因为没有把.env 文件放在了根目录下,而是错误的放在了src文件夹,导致vite启动的时候读不到文件.

后端日期格式化十二小时制

原因: 日期格式化的时候yyyy-MM-dd HH:mm::ss H要用大写,如果是小写的话h为十二小时制.

网格布局下图片宽高继承失效

先上来看一个简单的案例

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        img {
            width: 100%; /*跟父元素(body)保持相同的宽度*/
            height: 100vh; /*默认的盒子模型,父元素的高度是需要通过子元素来撑开的,所以默认父元素是没有高度的,也就是不能写100%,不然会造成高度塌陷*/
            object-fit: fill; /*默认图片的填充方式,其实不写也没事,这种填充方式是在指定宽高比例和图片宽高比例不一致的填充方式,拉伸图片来完全占满*/
        }
    </style>
</head>
<body>
    <img src="./background3.jpg" alt="" srcset="">
</body>
</html>

我们希望得到一个图片完全占满整个视窗,但是我们运行以后可以发现

  1. 四周有留白
  2. 纵向出现了滚动条

这是因为

  1. 一般浏览器都给body元素设置了一个8px默认外边距
  2. img是行内块元素，默认的图片对齐方式为vertical-align:baseline 基线对齐,所以是会留下基线到底部的空白的

如果我们想要实现预想的效果,需要修改为

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        body{
            margin: 0; /*清除默认的外边距*/
        }
        img {
            width: 100%; /*跟父元素(body)保持相同的宽度*/
            height: 100vh; /*默认的盒子模型,父元素的高度是需要通过子元素来撑开的,所以默认父元素是没有高度的,也就是不能写100%,不然会造成高度塌陷*/
            object-fit: fill; /*默认图片的填充方式,其实不写也没事,这种填充方式是在指定宽高比例和图片宽高比例不一致的填充方式,拉伸图片来完全占满*/
            display: block; /*转换为块元素,就不会存在基线和底部的空白了*/
        }
    </style>
</head>
<body>
    <img src="./background3.jpg" alt="" srcset="">
</body>
</html>

再来说回为什么在网格布局下,图片的宽高会有问题,我们先来看一看出问题的程序

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        body {
            height: 100vh; /*提前预设好高度,防止出现高度塌陷问题*/
            margin: 0; /* 清除默认的外边距 */
        }
        .layout {
            /*使用网格布局(2x2)*/
            display: grid; 
            grid-template-columns: repeat(2,1fr);
            grid-template-rows: repeat(2,1fr);
        }
        .layout img {
            width: 100%;
            height: 100%;
        }
    </style>
</head>
<body>
    <div class="layout" style="width: 100%; height: 100%;">
        <img src="./background3.jpg" alt="" srcset="">
        <img src="./background3.jpg" alt="" srcset="">
        <img src="./background3.jpg" alt="" srcset="">
        <img src="./background3.jpg" alt="" srcset="">
    </div>
</body>
</html>

我们预想的是实现一个占满整个屏幕的2x2的四分屏图片,现在的问题,这四张图片,组合在一起,出现了滚动条

其实这个问题出现在了**grid-template-columns: repeat(2,1fr);**这句话上面,1fr的其实隐式等于minmax(auto,1fr),也就是说最小值由内容决定,最大值由计算份数所占比例得出,我们图片是有默认高度的,也就是说,当我们图片的默认高度大于由分数计算出来的高度,他会取图片的默认高度来当作高度,而就不是网格布局计算出来的高度,从而导致,网格布局的高度被拉伸

所以我们应该修改为minmax(0,1fr),即下面的代码就为我们想要的结果

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        body {
            height: 100vh; /*提前预设好高度,防止出现高度塌陷问题*/
            margin: 0; /* 清除默认的外边距 */
        }
        .layout {
            /*使用网格布局(2x2)*/
            display: grid; 
            grid-template-columns: repeat(2,1fr);
            grid-template-rows: repeat(2,minmax(0,1fr));
        }
        .layout img {
            width: 100%;
            height: 100%;
        }
    </style>
</head>
<body>
    <div class="layout" style="width: 100%; height: 100%;">
        <img src="./background3.jpg" alt="" srcset="">
        <img src="./background3.jpg" alt="" srcset="">
        <img src="./background3.jpg" alt="" srcset="">
        <img src="./background3.jpg" alt="" srcset="">
    </div>
</body>
</html>
